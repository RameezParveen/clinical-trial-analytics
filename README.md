# Clinical Trial Analytics Project: Diabetes Treatment Efficacy Analysis

## Project Overview

This project analyzes a clinical trial dataset to compare two diabetes treatments: Auralin (oral insulin) and Novodra (injectable insulin). The objective is to explore treatment effectiveness, HbA1c changes, patient characteristics, BMI trends, and adverse drug reaction patterns using data analytics and visualization tools.

The project demonstrates an end-to-end analytics workflow, from data cleaning and transformation to KPI development, interactive dashboard creation, and insight reporting.

## Objectives

- Clean and validate clinical trial datasets.
- Handle missing values, duplicates, inconsistent formats, and data types.
- Transform and merge patient and treatment datasets using Power Query.
- Develop interactive dashboards using Microsoft Excel and Power BI.
- Create DAX measures for KPI reporting.
- Analyze HbA1c changes, treatment effectiveness, BMI, and adverse drug reactions (ADRs).

## Tools and Technologies

- **Microsoft Excel:** Data analysis, reporting, and dashboard development.
- **Power Query:** Data cleaning, transformation, standardization, and merging.
- **Microsoft Power BI:** Interactive dashboards and data visualization.
- **DAX:** KPI calculations and analytical measures.
- **Data Analytics:** Data validation, exploratory analysis, trend analysis, and insight generation.

## Dataset Overview

The project presentation describes two datasets:

| Dataset | Rows | Columns |
|---|---:|---:|
| Patients | 503 | 17 |
| Treatments | 350 | 11 |

The datasets contain information related to patient demographics, HbA1c measurements, treatment dosage, BMI, and adverse drug reactions.

The datasets were cleaned and merged using common identifiers. The dashboard displays 352 total patients for its reported analysis; this figure should be reconciled with the original dataset before drawing final conclusions about the analyzed population.

## Project Workflow

### 1. Data Cleaning and Validation
- Removed duplicate records and handled missing values.
- Corrected inconsistent date and numeric formats.
- Standardized data types and field formats.
- Performed data validation to support accurate reporting.

### 2. Data Transformation
- Used Power Query to transform and standardize data.
- Merged patient and treatment datasets using common identifiers.
- Prepared the cleaned data for dashboard development.

### 3. Dashboard Development
Created dashboards in Excel and Power BI to explore clinical trial data through interactive visualizations.

The Power BI dashboard includes:
- KPI cards
- Bar charts and line charts
- Donut charts
- Matrix tables
- Maps
- Slicers and filters
- Interactive treatment and patient analysis

### 4. DAX Measures and KPIs
Developed analytical measures to report:
- Total Patients
- Average HbA1c Start
- Average HbA1c End
- Average HbA1c Reduction
- Average BMI
- Drug Effectiveness
- Adverse Drug Reaction Count

## Key Findings

The dashboard displays the following overall KPI values:

| Metric | Displayed Value |
|---|---:|
| Total Patients | 352 |
| Average HbA1c at Start | 7.96 |
| Average HbA1c at End | 7.56 |
| Average HbA1c Reduction | 0.40 |
| Average BMI | 27.26 |

- Both treatments showed measurable HbA1c reductions in the presented analysis.
- The project compares treatment effectiveness using HbA1c-related measures.
- Adverse drug reaction patterns were visualized to explore patient safety indicators.
- Interactive filters enable analysis by drug, gender, age group, BMI, and adverse reaction.

These are descriptive findings from the project dashboard, not evidence of clinical equivalence or proof of treatment safety.
